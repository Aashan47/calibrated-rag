helpdesk-agent

A support agent that replies only from the help centre, cites the article, and escalates to a human when it can't.

Each incoming ticket gets either a reply draft with the article it came from, or an escalation with a hand-off note. The decision is made against a confidence threshold calibrated on labelled tickets, so the rate of wrong replies stays under a target you choose. Every search, decision and failed call is shown.

How this differs from a chatbot bolted onto the same model
Generic support chatbotThis agent
Where replies come fromThe model's training data plus whatever it infers; for a company it has never seen, it invents policyOnly the help-centre articles on the left; the article is cited
Ticket the help centre doesn't coverReplies anyway, plausiblyEscalates, with a hand-off note saying what was searched and why it stopped
ConfidenceNone, or a self-reported numberAgreement across N independent samples, gated by a threshold calibrated on 68 labelled tickets for a target error rate
RetrievalOne lookup, if anyAn agent loop: judges whether the articles suffice, reformulates the search when they don't, or stops
VisibilityA replyEvery search query, decision and sample vote; failures reported as failures, never as "can't answer"
