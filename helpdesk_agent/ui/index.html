How it works

  1. Search the help centre for the ticket, then let the agent judge: enough to reply, search again with a reworded query, or stop because it isn't covered.
  2. Draft several independent replies; confidence = how many agree on the same fact.
  3. Reply only if confidence clears a threshold calibrated on 68 labelled tickets for a target error rate; otherwise escalate with a hand-off note.
  4. A failed model call is shown as model unavailable, never as an escalation.

Unlike a chatbot on the same model, it never answers from memory. Try an uncovered ticket and press Compare with a plain chatbot. Numbers and method: EVALUATION.md.
