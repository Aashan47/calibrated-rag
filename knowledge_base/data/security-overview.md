# Security overview

Northwind is SOC 2 Type II and ISO 27001 certified; reports are available under NDA from security@northwind.app. Data is encrypted at rest with AES-256 and in transit with TLS 1.2 or higher. Production access requires hardware security keys and is logged. We run an independent penetration test every year and operate a public bug bounty programme. Our status page at status.northwind.app shows live availability and incident history.
