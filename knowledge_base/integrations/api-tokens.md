# API tokens

Personal API tokens are created under Profile › API tokens. Each user can have up to 10 active tokens, each with read-only or read-write scope. You can give a token an expiry of 30, 90 or 365 days, or none. A token is shown only once, at creation; if you lose it, revoke it and create a new one. Tokens act with the permissions of the user who created them. Workspace-level tokens that are not tied to a person are available on the Enterprise plan.
