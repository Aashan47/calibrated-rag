# Supported browsers and performance

Northwind supports the two most recent versions of Chrome, Firefox, Safari and Microsoft Edge. Internet Explorer is not supported. If the app is slow or pages fail to load, first check status.northwind.app for incidents, then clear the browser cache and disable extensions that modify pages, such as ad blockers. Workspaces with more than 50,000 tasks in a single project may load more slowly; archiving completed tasks helps.
