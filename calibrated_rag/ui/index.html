calibrated-rag-agent document question-answering that abstains

Ask a question. It answers only from the documents on the left, cites the passage, or tells you it can't.

Every answer comes with a confidence (agreement across several independent samples) checked against a threshold calibrated so that errors on answered questions stay under a target rate. When the documents don't support an answer, the agent abstains and says why instead of guessing. Every search, decision and citation it made is shown.

How this differs from asking ChatGPT or another chat assistant
Chat assistantThis agent
Where answers come fromIts training data, mixed with anything you paste; you can't tell which Only the passages in the knowledge base on the left. Nothing else.
When the answer isn't thereUsually produces a plausible answer anyway Abstains, and reports whether the agent judged it absent or the confidence was too low
ConfidenceNone, or a self-reported number that is poorly calibrated Agreement across N samples; the answer/abstain threshold is calibrated on held-out data for a target error rate
EvidenceSometimes a linkThe exact passage, highlighted in the knowledge base
VisibilityA replyThe full trace: each search query, each decision, each failed call
RetrievalSingle lookup, if anyAn agent loop: it judges whether the passages suffice and reformulates the query when they don't

Why it matters: for a company handbook, a contract, or a ticket history, a confident wrong answer is worse than no answer. This is a small, measured implementation of the "know when not to answer" layer (evaluation and numbers).
